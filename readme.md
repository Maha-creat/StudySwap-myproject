# StudySwap KZ — Онлайн курстар платформасы

## Сипаттама
StudySwap KZ — IT мамандықтарын үйренуге арналған оқу платформасы.
Қолданушылар курстарды іздей алады, сүзгілей алады және профиль жасай алады.

## Технологиялар
- HTML5 (семантикалық)
- CSS3 (айнымалылар, Flexbox, Grid, media queries)
- JavaScript (ES6+, localStorage)
- Фреймворксіз

## Беттер
| Бет | Сипаттама |
|-----|-----------|
| index.html | Басты бет — hero, артықшылықтар, модальді терезе |
| courses.html | Курстар — сүзгі, іздеу, курс қосу |
| profile.html | Профиль — форма валидациясы, localStorage |

## Интерактивті элементтер
1. **Burger-мәзір** — мобильді навигация
2. **Модальді терезе** — тегін сабаққа жазылу
3. **Сүзгі + іздеу** — курс аты мен санаты бойынша
4. **Курсты басу** — толық ақпарат пен жазылу терезесі
5. **Курс қосу** — форма арқылы тізімге қосу
6. **Форма валидациясы** — аты мен email тексеру
7. **localStorage** — профиль деректерін сақтау
